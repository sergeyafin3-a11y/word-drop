# WORD DROP — приложение для ученика

Персональный тренажёр разговорного английского под A1. Ученик открывает по ссылке
с телефона, дома тренирует слова сам, а на уроке вы вместе открываете раздел «Урок».

## Разделы (интерфейс на английском — ученик A1)

| Вкладка | Кто открывает | Что там |
|---|---|---|
| **Learn** | ученик сам | 6 активностей по выбранному набору |
| **Lesson** | преподаватель | 6 режимов говорения |
| **Grammar** | оба | правила с практикой |
| **Me** | ученик | XP, стрик, прогресс по наборам |

Наверху справа **☰** — меню наборов: сверху **New words** (пачка после каждого урока),
ниже **Topics** (каждая тема двумя строками: Words и Speaking phrases).

**Learn (лексика):** Cards с озвучкой и возвратом забытых слов, Match, Build it,
Type it по памяти, Sprint на 60 секунд с рекордом.

**Learn (Irregular verbs):** свой набор — Verb table по группам, Cards с тремя формами,
Match «глагол → прошедшее», Type the past, Type the 3rd form, Verb sprint.
Глаголы лежат в `irregular-data.js`, новые пачки дописываются в конец.

**Lesson:** Warm-up, Wheel (колесо вопросов), Speed round, Revision по словам, которые
он реально забывает, Dialogue с ролями и счётчиком фраз.

**Grammar:** формула → таблички → две строчки объяснения → ❌/✅ типичная ошибка →
примеры → две практики (Choose the form, Say it in English). Восемь правил:
Gerund, Infinitive, Present Simple, Present Continuous, Past Simple, How often,
Wh- questions, Articles.

**Articles (a · an · the)** объясняются методом «три вопроса»: можно посчитать? →
знает, какой именно? → один из многих? Идём сверху вниз и останавливаемся на первом
«да». Объяснение на русском, примеры из музыки, моды и шоу-биза. Три таблички:
метод, примеры по темам, «всегда the / всегда без артикля».

У правила можно задать до трёх таблиц (`table`, `table2`, `table3`) и ширины колонок:
`w: ['40%','40%','20%']` — чтобы всё влезало в телефон без горизонтальной прокрутки.

За каждый верный ответ капают очки: карточка +10, пара в Match +10, собранная фраза +15,
впечатанное слово +15, спринт +10 и бонус за комбо, сказанное предложение +20.
Прогресс хранится в браузере ученика: слова возвращаются через 1–2–4–8–16 дней.

## Warm-up: свой для каждой темы

Warm-up берёт всё из набора, который открыт в меню:

| Что | Откуда |
|---|---|
| вопросы | `questions` этой темы + 4 общих «как дела» в начале |
| слова | лексика этого же набора (если пачка маленькая — добирается из её темы) |
| обои | эмодзи слов этой темы, на каждый вопрос свой набор |

Открыл Hobbies — разогрев про хобби на гитарах и джойстиках. Открыл Daily Routine —
про режим дня на будильниках и блинчиках. Пачка «New words · Hobbies» подтягивает
вопросы и обои темы Hobbies (связь по названию). Всегда 15 вопросов + 15 слов.

Новая тема получает всё это сама, дописывать ничего не нужно — обои собираются
из эмодзи её слов. Хотите задать обои вручную — четвёртое поле в заголовке:

```
# TOPIC | Travel | ✈️ | 🧳✈️🗺️
```

## Картинки к вопросам вне тем

Если темы нет (например, Irregular verbs), эмодзи подбираются по смыслу самого
вопроса: про еду — пицца, про игры — джойстики, про погоду — солнце. Эмодзи рисует
сам телефон, из интернета ничего не грузится, работает и без связи.

Списки лежат в `stickers.js`. Свой набор — одна строка:

```js
{ k: ['skate', 'skateboard', 'roller'], e: ['🛹', '🛼', '😎'] },
```

`k` — слова, по которым ищем (по началу слова: `music` поймает `musical`),
`e` — три эмодзи. Строка выше по списку выигрывает, поэтому более узкие темы
ставьте раньше общих. Если ничего не совпало, берётся нейтральный набор — пустым
вопрос не останется.

Оформление меняется одним словом в `index.html`: `<html data-sticker="wall">`.
Есть ещё `sticker` (одна большая наклейка), `collage`, `polaroid`, `reaction`,
`bubble` и `none` (совсем без картинок). Посмотреть все — открыть
`preview-stickers.html` в браузере (в GitHub этот файл заливать не нужно).

## Вкладка Homework: домашка по темам

Домашка построена по методике: сначала заметить, потом присвоить фразой,
потом сказать про себя, потом рассказать бегло. Пять блоков подряд:

| Блок | Что делает ученик | Зачем |
|---|---|---|
| **1 · Find the words** | ищет слова в тексте сам, подсказок нет | noticing: то, что нашёл сам, запоминается |
| **2 · Say these phrases** | 🔊 и говорит фразу три раза | учим не слова, а готовые куски речи |
| **3 · Fill and say** | вписывает слово и говорит предложение вслух | точность |
| **4 · Your turn** | отвечает про себя вслух | без личного слово не приживается |
| **5 · Tell it three times** | один рассказ трижды, каждый раз быстрее и короче | беглость |
| **Questions** | не трогает | это вам на урок |

**Слова в тексте ничем не выделены.** Кликабельно каждое слово: нужное зеленеет
и даёт +5 XP с переводом, лишнее просто вздрагивает и ничего не подсказывает.

Всё в `homework-data.js`:

```js
{
  id: 'hw-travel-airport',
  topic: 'Travel · Airport',
  title: 'Five Suitcases and One Gate',
  story:   [ { en: '...', ru: '...' } ],
  find:    [ { en: 'gate', ru: 'выход на посадку' } ],
  chunks:  { note: '...', items: [ { en: 'How long is the delay?', ru: '...' } ] },
  gaps:    [ { s: 'How long is the ___?', a: 'delay' } ],
  mine:    { note: '...', items: [ 'Window seat or aisle seat? ...' ] },
  linkers: [ { en: 'First', ru: 'сначала' } ],
  retell:  { note: '...', items: [ '...' ], use: '...' },
  questions: [ '...' ]
}
```

Проценты считаются от всего: 12 слов + 6 фраз + 10 пропусков + 5 «про себя»
+ 3 пересказа = 36 шагов. Сделанное едет по коду переноса.

## Вкладка Topics: ваши HTML-уроки целиком

Уроки, которые вы делаете в HTML, переносить и переписывать **не нужно**. Файл кладётся
рядом с остальными и открывается внутри приложения как есть — со своим оформлением,
кнопками, озвучкой и галочками.

Как добавить новый урок:

1. Положите файл рядом с `index.html`, например `lesson-food.html`.
   Имя без папок — иначе при перетаскивании в GitHub файл потеряется.
2. Откройте `lessons-data.js` и допишите блок:

```js
{
  id: 'food',                    // латиницей, потом не менять
  title: 'Food',                 // как называется у ученика
  sub: 'A1–A2 · 4 chapters',
  emoji: '🍕',
  file: 'lesson-food.html',
  date: '25 Aug'
}
```

**Список упражнений собирается сам** — по заголовкам `<h2>`, которые уже есть в вашем файле.
Ученик открывает урок, жмёт ☰ в правом верхнем углу и находит нужное упражнение
по названию. Если оно в другой главе, приложение само её откроет.

**Домашка.** Отдельного раздела нет: вы просто пишете ученику название упражнения,
он открывает урок и находит его через ☰.

Что важно знать:

- Прогресс урока (галочки, ответы) хранится **отдельно** от прогресса приложения.
  XP и стрик от уроков не меняются, и наоборот — уроки ничего не сбивают.
- iframe изнутри не прокручивается, особенно на айфоне, поэтому приложение
  растягивает урок на всю высоту и листает его само. Ничего настраивать не нужно.
- Файл урока может быть тяжёлым: в примере 361 КБ, из них 297 КБ — встроенные картинки.
  Это нормально, но десяток таких уроков заметно утяжелит репозиторий.

## Как добавить лексику нового урока

Открываете `data.js`, в самом низу файла блок `window.QUICK` между кавычками ` `.
Пишете обычными строками — скобок и запятых нет, сломать нечем:

```
# NEW WORDS | Lesson 2 | 10 Aug
go on a trip - поехать в путешествие - ✈️
book a hotel - забронировать отель - 🏨

# TOPIC | Travel | ✈️
= words
a suitcase - чемодан - 🧳
= phrases
I would like to travel alone - я бы хотел путешествовать один
= questions
Where would you like to go?
```

Что значат строки:

| Строка | Что делает |
|---|---|
| `# NEW WORDS \| Lesson 2 \| 10 Aug` | новая пачка после урока — появится в меню сверху |
| `# TOPIC \| Travel \| ✈️` | новая тема. Если название совпадает с существующей — слова допишутся в неё |
| `= words` | дальше идут просто новые слова |
| `= phrases` | дальше идут структуры для речи (I like…, I would like to…) |
| `= questions` | дальше идут вопросы для говорения на уроке |
| `слово - перевод - эмодзи` | сама строка, эмодзи можно не писать |
| `// текст` | заметка для себя, в приложение не попадёт |

Всё остальное приложение делает само: карточки, Match, Build it, Type it, Sprint,
Sort & Say и вопросы на уроке соберутся из этих строк.

Если после правки экран пустой и написано «Не читается data.js» — значит
случайно стёрлась кавычка ` в начале или конце блока. Вернуть её — и всё заработает.

**Старый способ** (объектами `window.BATCHES` и `window.TOPICS` выше в файле) тоже
работает — он просто строже к запятым.

## Прогресс ученика: что его НЕ сбивает

Прогресс лежит в браузере ученика и привязан **к самому слову**, а не к его месту
в списке и не к названию группы. Проверено на живом сценарии: ученик выучил 28 слов,
набрал 4820 XP, стрик 3 дня, рекорд спринта 240 и прошёл 18 из 32 заданий Present Simple.
После этого добавлены новая тема, новая пачка, новые слова в середину старой темы и новое
правило — все цифры остались теми же до единицы.

Можно спокойно:

- добавлять новые темы, пачки и правила грамматики;
- дописывать слова в начало, конец и середину существующей темы;
- переставлять строки, удалять лишние, менять переводы и эмодзи;
- заливать в GitHub заново хоть все файлы сразу.

Если тему удалить или переименовать, а ученик как раз на ней стоял — приложение молча
переключит его на первый доступный набор, пустого экрана не будет.

Сбросится прогресс только по одному слову и только если поменять **само английское
написание** (`take photos` → `take a photo` — это уже другое слово). Русский перевод,
эмодзи и порядок можно менять как угодно.

При добавлении новых заданий в существующее правило проценты по нему просядут
(решено 18, а всего стало 40) — это честно: прогресс считается по пройденным заданиям.

### Почему прогресс всё-таки может показаться нулевым

Прогресс лежит **в конкретном браузере на конкретном устройстве**. Он обнулится на вид, если:

- открыть с иконки на домашнем экране, а потом ту же ссылку в Safari — на iPhone это **два
  разных хранилища**, у каждого свой прогресс;
- открыть в другом браузере (Chrome вместо Safari) или на другом устройстве;
- открыть в приватном окне;
- Safari сам вычистил данные сайта, куда давно не заходили (иконку с домашнего экрана
  он так не чистит — поэтому ученику надо открывать именно её).

На этот случай в **Me** внизу есть **My progress code**: «Copy my code» даёт длинную строку,
«Paste a code» её принимает. Восстановление ничего не стирает — оно **сливает** два прогресса
и оставляет лучшее (XP по максимуму, рекорд по максимуму, слова и решённые задания
объединяются). Вставить старый код поверх свежего безопасно.

Единственное, чего делать нельзя: менять строчку `KEY = 'wordDrop.v2'` в `core.js` —
это адрес, по которому лежит весь прогресс.

## Как выложить ссылку (GitHub Pages, бесплатно)

1. Заведите аккаунт на **github.com** (если нет).
2. **New repository** → имя, например `word-drop` → **Public** → Create.
3. На странице репозитория: **Add file → Upload files** → перетащите туда
   все файлы (⌘A в папке) → **Commit changes**.
4. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
5. Через минуту появится ссылка вида `https://ВАШ-ЛОГИН.github.io/word-drop/` — её и
   отправляете ученику. На телефоне: «Поделиться → На экран Домой», получится иконка
   как у обычного приложения.

**Обновление лексики:** в репозитории откройте `data.js` → карандашик (Edit) →
вставьте новую группу → Commit. Через минуту у ученика по той же ссылке новые слова.
Его прогресс при этом сохраняется.

## Оформление

Тема — **Midnight** (тёмно-синий + голубой, шрифт Space Grotesk). Задаётся одним словом
в `index.html`: `<html data-theme="midnight">`. В `css/style.css` сверху лежат ещё девять
палитр — `mint`, `sky`, `peach`, `bubble`, `candy`, `sand`, `grape`, `forest`, `ink`.
Поменять оформление = поменять это слово.
