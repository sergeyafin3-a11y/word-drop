# WORD DROP — приложение для ученика

Персональный тренажёр разговорного английского под A1. Ученик открывает по ссылке
с телефона, дома тренирует слова сам, а на уроке вы вместе открываете раздел «Урок».

## Разделы (интерфейс на английском — ученик A1)

| Вкладка | Кто открывает | Что там |
|---|---|---|
| **Learn** | ученик сам | 6 активностей по выбранному набору |
| **Lesson** | преподаватель | 6 режимов говорения |
| **Grammar** | оба | правила с практикой |
| **Me** | ученик | XP, стрик, прогресс по наборам |

Наверху справа **☰** — меню наборов: сверху **New words** (пачка после каждого урока),
ниже **Topics** (каждая тема двумя строками: Words и Speaking phrases).

**Learn:** Sort & Say (раскладывает занятия по полкам I love / I like / I don't like /
I hate / I would like to, приложение строит правильное предложение с V-ing и предлагает
добавить деталь), Cards с возвратом забытых слов, Match на скорость, Build it,
Type it по памяти, Sprint на 60 секунд с рекордом. Внизу — See all words.

**Lesson:** Warm-up, Wheel (колесо вопросов), Speed round, Revision по словам, которые
он реально забывает, Dialogue с ролями и счётчиком фраз, Sort & Say вдвоём.

**Grammar:** формула → две строчки объяснения → ❌/✅ типичная ошибка → примеры →
две практики (Choose the form, Say it in English).

За каждый верный ответ капают очки: карточка +10, пара в Match +10, собранная фраза +15,
впечатанное слово +15, спринт +10 и бонус за комбо, сказанное предложение +20.
Прогресс хранится в браузере ученика: слова возвращаются через 1–2–4–8–16 дней.

## Как добавить лексику нового урока

Открываете `data.js`, в самом низу файла блок `window.QUICK` между кавычками ` `.
Пишете обычными строками — скобок и запятых нет, сломать нечем:

```
# NEW WORDS | Lesson 2 | 10 Aug
go on a trip - поехать в путешествие - ✈️
book a hotel - забронировать отель - 🏨

# TOPIC | Travel | ✈️
= words
a suitcase - чемодан - 🧳
= phrases
I would like to travel alone - я бы хотел путешествовать один
= questions
Where would you like to go?
```

Что значат строки:

| Строка | Что делает |
|---|---|
| `# NEW WORDS \| Lesson 2 \| 10 Aug` | новая пачка после урока — появится в меню сверху |
| `# TOPIC \| Travel \| ✈️` | новая тема. Если название совпадает с существующей — слова допишутся в неё |
| `= words` | дальше идут просто новые слова |
| `= phrases` | дальше идут структуры для речи (I like…, I would like to…) |
| `= questions` | дальше идут вопросы для говорения на уроке |
| `слово - перевод - эмодзи` | сама строка, эмодзи можно не писать |
| `// текст` | заметка для себя, в приложение не попадёт |

Всё остальное приложение делает само: карточки, Match, Build it, Type it, Sprint,
Sort & Say и вопросы на уроке соберутся из этих строк.

Если после правки экран пустой и написано «Не читается data.js» — значит
случайно стёрлась кавычка ` в начале или конце блока. Вернуть её — и всё заработает.

**Старый способ** (объектами `window.BATCHES` и `window.TOPICS` выше в файле) тоже
работает — он просто строже к запятым.

## Прогресс ученика: что его НЕ сбивает

Прогресс хранится в браузере ученика и привязан **к самому слову**, а не к его месту
в списке и не к названию группы. Поэтому спокойно можно:

- добавлять новые слова в начало, конец и середину любой темы;
- переставлять строки местами и удалять лишние;
- переименовывать темы и пачки, менять эмодзи;
- заливать в GitHub заново хоть все файлы сразу.

Выученное останется выученным, XP, стрик и рекорд спринта тоже.

Сбросится прогресс только по одному слову и только если поменять **само английское
написание** (`take photos` → `take a photo` — приложение считает это новым словом).
Русский перевод, эмодзи и порядок менять можно как угодно.

Единственное, чего делать нельзя: менять строчку `KEY = 'wordDrop.v2'` в `core.js` —
это адрес, по которому лежит весь прогресс.

## Как выложить ссылку (GitHub Pages, бесплатно)

1. Заведите аккаунт на **github.com** (если нет).
2. **New repository** → имя, например `word-drop` → **Public** → Create.
3. На странице репозитория: **Add file → Upload files** → перетащите туда
   все файлы (⌘A в папке) → **Commit changes**.
4. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
5. Через минуту появится ссылка вида `https://ВАШ-ЛОГИН.github.io/word-drop/` — её и
   отправляете ученику. На телефоне: «Поделиться → На экран Домой», получится иконка
   как у обычного приложения.

**Обновление лексики:** в репозитории откройте `data.js` → карандашик (Edit) →
вставьте новую группу → Commit. Через минуту у ученика по той же ссылке новые слова.
Его прогресс при этом сохраняется.

## Оформление

Тема — **Midnight** (тёмно-синий + голубой, шрифт Space Grotesk). Задаётся одним словом
в `index.html`: `<html data-theme="midnight">`. В `css/style.css` сверху лежат ещё девять
палитр — `mint`, `sky`, `peach`, `bubble`, `candy`, `sand`, `grape`, `forest`, `ink`.
Поменять оформление = поменять это слово.

```

data.js      ← ЛЕКСИКА И ГРАММАТИКА (обновляется каждый урок)
quick.js     разбор простого текстового формата
core.js      прогресс, XP, стрик, интервальное повторение
home.js      активности для дома
sort.js      Sort & Say
grammar.js   раздел грамматики
lesson.js    режимы для урока
app.js       вкладки, меню и экраны

Все файлы лежат в одной папке без вложенности — так их проще
перетаскивать в GitHub, ничего не теряется.
```
